# 最速PFC・カロリー管理 Webアプリ (PWA)

自炊中心・固定食材派のための「最速PFC・カロリー管理Webアプリ」です。  
既存の検索型アプリのような面倒な文字入力や候補選択は不要。よく食べる食材パーツを**1タップで即座に加算**し、あとから量（グラム数や倍率）を**瞬時に微調整**できます。

---

## ⚡ 特徴・機能

1. **1タップ加算（最速の記録体験）**
   - 主食・主菜・副菜の定番食材パーツをワンタップするだけで今日の履歴に即時追加。
   - 触覚フィードバック（スマホのバイブレーション）とトースト通知で軽快に記録。

2. **あとから瞬時に量を微調整（再計算バグ完全防止設計）**
   - 履歴カード上で `[-50g]` `[-10g]` `[+10g]` `[+50g]` や `[0.5x]` `[1.5x]` をワンタップ。
   - スライダー・数値入力モーダルによる自由な微調整にも対応。
   - 基準量（母数）を保持し、`round1(baseMacro * (currentAmount / baseAmount))` により小数第1位まで正確にリアルタイム再計算。

3. **リアルタイムPFC & カロリーメーター**
   - 目標カロリーとPFC比率（例: 30:20:50）から換算した目標グラム数・残りグラム数をリアルタイム表示。
   - プログレスバーで現在の達成状況と過不足が一目で把握可能。

4. **自炊派のための食材パーツ管理**
   - よく食べる食材パーツ（白米、鶏むね肉、卵、オートミール、プロテイン等）を自由に追加・編集・削除。
   - 基準量あたりのPFCを入力するとカロリーを自動プレビュー。

5. **日付またぎ自動リセット & バックアップ**
   - 日付が変わると当日の履歴（`todayLogs`）を自動リセットし、前日ログはアーカイブに退避。
   - プリセットや目標設定はそのまま保持。
   - JSON形式でのエクスポート/インポート（端末移行も安心）。

6. **スマホ全画面PWA対応（ホーム画面追加）**
   - アドレスバーやツールバーのない、ネイティブアプリ同様の全画面スタンドアロン表示。
   - 完全オフライン動作対応（Service Worker / Workbox）。

---

## 📱 スマホでの全画面（PWA）利用方法

1. **PCと同じWi-Fi環境**で `npm run dev -- --host` を実行
2. スマホのブラウザ（Safari または Chrome）でターミナルに表示されたローカルIP（例: `http://192.168.x.x:5173/`）を開く
3. **ホーム画面に追加**:
   - **iOS (Safari)**: 画面下の共有ボタン（四角から矢印） ➔ **「ホーム画面に追加」**
   - **Android (Chrome)**: 右上のメニュー（三点リーダー） ➔ **「アプリをインストール」** または **「ホーム画面に追加」**
4. ホーム画面に追加された「最速PFC」アイコンをタップすると、Safari/Chromeのバーが消えて**ネイティブアプリ同様のフルスクリーン**で起動します！

## 💻 開発コマンド

```bash
# 開発サーバー起動
npm run dev

# スマホから同一Wi-Fiでアクセスする場合
npm run dev -- --host

# 本番ビルド & 型チェック
npm run build

# 本番ビルドのプレビュー
npm run preview
```
